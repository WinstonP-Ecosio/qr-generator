# 🔳 QR Code Generator for Designers

A super lightweight and fast web tool to generate QR codes from any URL. It is specially designed for the design workflow, allowing you to download the generated codes in both **PNG** (for quick screen use) and **SVG** (vector format, perfect for Figma, Illustrator, or high-res printing without losing quality).

## ✨ Features

- **100% Client-side:** No backend or database required. All generation happens securely directly in the user's browser.
- **Vector (SVG) & Raster (PNG) Export:** Direct one-click download.
- **Super lightweight & portable:** Everything works from a single HTML file with embedded CSS and native JavaScript.
- **Reliable library:** Uses the robust `qrcode-generator` library via CDN.

## 🚀 How to Use

It's the easiest app to deploy! No need to install Node.js, NPM, or configure local servers.

1. Clone this repository to your local machine or simply download the `index.html` file.
2. Double-click the `index.html` file to open it in your favorite web browser (Chrome, Safari, Firefox, etc.).
3. Paste the desired URL, click "Generate QR", and choose your download format.

> **Tip for free hosting:** You can upload this repository to [GitHub Pages](https://pages.github.com/), [Vercel](https://vercel.com/), or [Netlify](https://www.netlify.com/) in seconds to host it online for free and share the link with your entire team.

- **Vanilla JavaScript** (Core application logic)
